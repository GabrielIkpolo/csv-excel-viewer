# Quick Start - CSV & Excel Viewer

## 🚀 Get Started in 3 Steps

### Step 1: Install the Extension
1. Download or navigate to the `csv-excel-viewer-1.0.0.vsix` file
2. Open VS Code
3. Press `Ctrl+Shift+P` and type "Extensions: Install from VSIX..."
4. Select the .vsix file and click Install

### Step 2: Reload VS Code
**IMPORTANT:** You MUST reload VS Code for the changes to take effect
- Press `Ctrl+Shift+P`
- Type "Developer: Reload Window"
- Press Enter

### Step 3: Open a File
**Method A: Right-Click Context Menu (New!)**
1. Open a CSV or Excel file in VS Code
2. Right-click on the file in the Explorer panel
3. Select **"Open in CSV/Excel Viewer"**
4. The file displays as a table!

**Method B: Activity Bar**
1. Click the **CSV/Excel Viewer** icon (📊) in the Activity Bar
2. Click "Open File" to select a CSV or Excel file

**Method C: Command Palette**
1. Press `Ctrl+Shift+P`
2. Type "CSV & Excel Viewer"
3. Select **"Open in CSV/Excel Viewer"**

## ✨ Features

- 📊 View CSV files in table format
- 📈 View Excel (.xlsx) files in table format
- 🔍 Search and filter data
- 🎨 Dark theme optimized for VS Code

- 🚀 No external dependencies

## 🎯 Tips

1. **Sticky Headers:** Table headers stay visible while scrolling
2. **Search:** Type in the search box to filter rows
3. **Icons:** CSV files show green icons, Excel files show blue icons
4. **Language Support:** CSV files are now recognized as CSV format
